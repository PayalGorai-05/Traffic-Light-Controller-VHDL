# Traffic Light Controller with Pedestrian Override using VHDL

## Overview
Designed and simulated an FSM-based traffic light controller using VHDL in Vivado.

## Features
- Red, Yellow and Green signal sequencing
- Pedestrian override functionality
- FSM-based control logic
- Behavioral simulation verification

## Tools Used
- VHDL
- Vivado

## Project Structure

Traffic-Light-Controller-VHDL
├── src
├── tb
└── simulation

## Result
Successfully verified state transitions and pedestrian override operation using waveform simulation.
